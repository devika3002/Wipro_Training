# Responsive Customer Engagement Portal

## Project Overview
This project is a responsive customer engagement portal developed using HTML, CSS, Bootstrap, and JavaScript.  
It demonstrates structured HTML, external styling, responsive layout, accessibility, and basic interactivity.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)


## User Stories Implemented
- US-01: Structured and semantic HTML page
- US-02: Usage of inline and block elements
- US-03: Form to collect user information
- US-04: Semantic HTML with accessibility support
- US-05: Audio and video embedded with controls
- US-06: External CSS for styling
- US-07: CSS selectors and box model
- US-08: Responsive layout using Bootstrap and
   modern CSS units
- US-09: Modern CSS features
- US-10: Bootstrap cards and layout components
- US-11: Navigation bar implementation
- US-12: Form styling and validation using Bootstrap
- US-13: JavaScript logic for interaction
- US-14: DOM manipulation and event handling
- US-15: Asynchronous data fetching using Fetch API


## How to Run the Project
1. Open the project folder in VS Code
2. Open `index.html` in Google Chrome or Microsoft Edge  
   (or use Live Server for best results)


## Accessibility Features
- Semantic HTML elements
- Labels for form inputs
- Media controls enabled
- Readable layout and contrast


## Media Note
Audio and video are embedded using HTML5-compatible sources for demonstration purposes.



## Browser Compatibility
- Google Chrome (latest)
